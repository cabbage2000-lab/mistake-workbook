# 错题打印助手 PRD

版本：v0.3  
状态：需求草案，可用于产品评审与开发拆分；尚未实施  
日期：2026-11-09（Asia/Shanghai）  
项目目录：`mistake-workbook`  
产品形态：由 AI 宿主执行的 skill，以对话组织流程，以 HTML 提供预览，以 PDF 交付打印材料  
产品名称：“错题打印助手”为暂定名

## 1. 问题陈述

家长希望把孩子经常做错的数学、语文、英语题整理成可以再次练习的纸质材料。目前需要从试卷、练习册或照片中选题，再手动录入、截图、调整格式、安排答题空间和分页，最后转换为可打印文件。整理时间常常花在排版上，同一套材料还容易出现字太小、图不完整、题目跨页、没有地方作答等问题。

本项目交付一个可安装、可复用的 skill。家长在 AI 宿主的对话中提供错题，skill 引导模型整理题面、确认疑点和选择排版，再调用脚本按选定的 A3 或 A4 纸型生成预览与 PDF。家长通过自然语言提出修改，模型更新结构化题目和排版设置，脚本负责稳定生成文件。

### 1.1 已确认的需求

- 使用对象为家长，练习对象为学生。
- 项目以 skill 为产品与交付形态，主要交互发生在 AI 宿主的对话中。
- 错题由家长提供，覆盖数学、语文、英语等学科。
- 输入包括文本或照片；照片可以使用视觉模型解析。
- 核心流程固定为：提供错题 → 整理题目 → 确认疑点 → 选择排版 → 预览 → 导出 PDF。
- 支持 A3、A4 两种纸型供家长选择，自动完成适合所选纸型打印的排版，减少家长操作时间。
- 用户描述中包含“试卷”且未明确指定纸型时，默认理解为 A3；其他未指定纸型的任务默认使用 A4。用户明确指定的纸型优先。
- 输出 PDF，家长下载后可以直接打印。
- 沿用已有技术方向，可以使用 Pretext 作为文本测量能力的基础。

### 1.2 本稿的产品假设

以下为建议默认值，不代表用户已经逐项确认；不影响先验证核心闭环。

- 首版提供中文对话指引，优先覆盖小学常见错题；具体宿主与分发方式待实现时确定。
- 宿主提供文字/图片读取、视觉理解、文件读写与脚本执行能力；skill 本身不包含独立视觉模型或 OCR 服务。
- “错题本”首先指本次选题形成的重做练习纸；长期错题库与复习计划后续评估。
- 首版以原题重做为主，保留原题条件与来源信息，默认按学科、题型归类为试卷，同类题内保留相对顺序，不默认生成同类题或解析。
- skill 不额外引入账号体系，也不要求学生实名；年级为可选项，未填时使用通用排版。
- P0 输入为文字、照片与截图；PDF 输入作为后续扩展，不直接解析 Word、Excel 或压缩包。
- 默认使用本地工作目录保存本次任务与生成文件；跨会话恢复需读取任务文件，不依赖模型记住完整对话。

## 2. 产品目标与成功标准

### 2.1 目标

1. 家长不需要操作 Word 或逐题调整位置，就能得到可打印的练习纸。
2. 保证入选题目完整、可读、可作答，减少遗漏题干、图示或条件的风险。
3. 自动处理题量变化、题干长短和不同题型的书写空间。
4. 对识别不确定的内容给出来源定位与集中确认清单，减少逐题人工检查的负担。

### 2.2 评估指标

下表为待验证的产品目标，不能当作已实现的性能或识别准确率。

| 指标 | 定义与建议目标 | 验证方式 |
| --- | --- | --- |
| 家长整理耗时 | 同一组 20 道题，从选定素材到获得 PDF，中位耗时较手动整理减少至少 50% | 邀请至少 5 位家长，对相近难度材料记录操作时间；识别等待时间另行记录 |
| 输入完整性 | 素材、候选题、入选题、排除题数量可追溯，无静默遗漏 | 对照来源清单与题目清单 |
| 导出完整性 | 入选且已确认的题目全部进入学生 PDF，无重复、缺失或无提示截断 | 自动题目 ID 对账及人工抽查 |
| 打印可用性 | 验收样张符合选定的 A3/A4 尺寸，无正文越界、缺图、异常空白页、答案误入学生卷 | 两种纸型的 PDF 尺寸检查、页面截图、纸质抽打 |
| 流程完成率 | 家长能在对话中完成六步流程，并取得可打开的预览和 PDF；记录实际完成率后再定业务阈值 | 在目标宿主中进行小范围可用性测试 |

识别质量按学科、题型和素材清晰度分开统计；不承诺任意照片都能无误识别。题面是否正确与排版是否正确分别验收。

P0 为首版交付要求；P1 为后续候选能力，不计入首版验收。

| 模块 | P0：首版 | P1：后续评估 |

| 题目整理 | 模型分题、建议学科和题型、来源对照；通过对话修正、合并/拆分、排序及排除 | 自动去重、知识点标签 |
| 三科模板 | 常见数学计算/应用题、语文词语/拼音/通用题、英语默写/通用题 | 更细的教材模板、描红、复杂图形重绘 |

| 答案 | 学生卷去除旧作答；可选独立答案册，仅包含已核对答案 | 自动解题、完整解析 |
| 保存 | 工作目录内保存任务 JSON、来源引用、修订与生成结果；可从任务文件继续 | 跨设备同步、长期错题库 |

不自动判断整页试卷哪些题做错。系统识别候选题，家长选择需要收录的题；教师批改符号可以作为提示，不能作为唯一选题依据。

## 4. 解决方案与关键流程

### 4.1 主流程

1. **提供错题**：家长在对话中粘贴题目或附上照片/截图；年级与练习纸标题可选。模型先核对素材是否可读取，为来源编号。
2. **整理题目**：文本直接结构化；照片由宿主视觉模型转录。模型区分题干、选项、图示、小题、旧作答和批注，保留来源原题号与稳定 ID，按学科和题型返回试卷分组及输出题号摘要。家长可以修正、合并、拆分或排除题目；整页素材需明确收录范围。
3. **确认疑点**：按题号集中列出模糊符号、缺失条件、图示与旧作答分离问题，并给出来源位置。家长逐项补充、修正、明确确认或排除；模型不猜测未决内容。无疑点且校验通过时，说明结果后继续下一步。
4. **选择排版**：提供 A3、A4 两种纸型，以及标准、紧凑、宽松三个方案，说明当前纸型、字号、栏数和书写空间；按题型推荐方案。用户明确指定纸型时直接采用，否则描述包含“试卷”默认选 A3，其余默认选 A4，并说明所用纸型。家长可改选纸型或方案，也可用“应用题多留两行”等自然语言调整；已有明确偏好时直接沿用。
5. **预览**：按选定纸型生成可打开的 HTML 和实际页面缩略图，返回纸型、题数、页数、排版摘要及预览链接。家长可提出修改；题面改动返回疑点校验，纸型或排版改动重新分页，更新预览版本。
6. **导出 PDF**：基于同一修订的已确认内容和预览设置生成学生版 PDF，完成文件与页面检查，返回下载链接、题数、页数和打印说明。用户已要求导出且无需修改时，在呈现预览后继续完成导出。

六步是工作阶段，不要求固定六轮对话。仅在疑点或影响结果的缺失选择处提问；未指定排版且用户要求直接生成时，说明采用标准方案并继续。家长可排除暂时无法确认的题目，继续生成其他题目；回复中须明确列出排除项。未解决疑点只允许生成标注问题的草稿预览，不能作为正式练习导出。

### 4.2 各阶段的对话与文件产物

| 阶段 | 向家长展示的内容 | 内部记录或文件 |
| --- | --- | --- |
| 提供与整理 | 素材编号、题目清单、来源和识别结果摘要 | 来源索引、结构化题目 |
| 确认疑点 | 题号、具体疑点、原图位置与待补充信息 | 疑点清单、确认状态 |
| 选择排版 | A3/A4 选项、当前纸型、方案说明与本次采用的设置 | 含纸型的排版配置 |
| 预览 | HTML 链接、页面缩略图、纸型、题数与页数 | 当前修订的预览文件与布局报告 |
| 导出 | PDF 链接、纸型、修订信息与打印说明 | PDF、导出检查报告 |

题面编辑、选题和排版修改均通过对话完成，HTML 用于查看打印效果。展示全部页面的缩略图或可逐页查看的预览；仅返回源代码或内部 JSON 不算完成预览。

| US-08 | 作为家长，我想在识别或导出失败后继续处理 | 已保存的题目与设置可从任务文件恢复，错误原因明确，可重试失败步骤 |

## 6. 功能需求

### FR-01 素材导入

- 通过宿主接收粘贴文字，以及 JPEG、PNG、WebP 照片/截图；实际可读格式和附件大小受宿主能力约束。
- 先核对收到的素材数量与可读性。无法访问附件、图片模糊或格式不支持时，明确指出具体素材，请家长补充文字或更清晰图片。
- 必要时通过宿主工具旋转或裁剪题目区域，保留原始来源；工具不可用时说明限制，不假装已经完成图像处理。
- 每份文字、来源文件和图片区域均有稳定 ID，识别结果可以追溯到具体来源；区域至少有可读位置描述，有工具支持时记录坐标。
- 建议首版按每批 10 张图片、正式练习 100 题验证；具体文件限制继承宿主约束。超出已验证范围时明确说明并分批处理，不静默截取。
- PDF 输入不列为 P0；后续支持时需增加页选择、来源页追踪及不可读文件处理。

### FR-02 题目识别与分题

- 文字由模型直接整理；照片由宿主视觉模型读取，区分题干、选项、必要图示、关联小题、学生作答及教师批注，识别结果以候选内容呈现。生成脚本只接受结构化数据，不承担 OCR 或题意理解。
- 优先保留原题含义、条件、数字、单位、标点和小题关系；不自行改编、补齐缺失条件或输出解题过程。
- 学科和题型可以建议，家长可以修正；未识别到具体类型时使用通用题模板。
- 只有家长选中的候选题进入练习纸。整页含多题、跨页阅读材料、共用题图等情况允许合并为复合题。
- 在对话中展示来源覆盖情况与处理结果。无法判断是否漏题时保留“需要检查来源”的状态，不宣称已完整识别。

### FR-03 校对与编辑

- 整理清单包含题号、题面摘要、题型、来源和状态；家长可以用自然语言修正文本、公式、选项及书写空间，必要时展开完整题面与题图对照。
- 数学重点标记负号、小数点、分数、乘除号、单位及图形标注；语文重点标记生僻字、多音字与拼音声调；英语保留大小写、词形和标点。
- 只集中追问需要确认的题目，并按稳定题号关联家长回复。无疑点且校验通过的题目可直接进入已确认状态；疑点题需修正或由家长明确确认后才能进入正式 PDF。
- 编辑题面、合并/拆分题目或重新识别后，该题重新进入待确认状态；调整纸型、字号、留白或顺序只使预览失效，不要求再次确认题意。
- 不向家长展示来源不明的识别置信百分比；使用“文字模糊”“图示待确认”等具体原因。只回答部分疑点时，其余项继续保留为待确认，不因用户同意排版而自动视为题面已确认。

### FR-04 原题重做与图示保留

- 默认输出干净题面，去掉能可靠分离的学生答案、批改痕迹和解题过程。
- 原图中印刷题干与手写答案重叠时，不能直接宣称已清除。在对话中说明问题，并提供转录修正、保留题图或排除此题三个处理方向。
- 题图模式必须保留解题所需区域；允许裁剪、旋转和调整打印宽度，不默认重绘几何关系或图形比例。
- 若保留题图仍含作答，须明确提示并由家长确认按原图保留，不将该题标记为“已去作答”。
- 题图缩放后保持比例；若关键文字或标注已经不可读，要求换图、调整布局或排除，不通过极小缩放隐藏问题。

### FR-05 三科题型与书写区

| 学科/题型 | 首版布局 | 建议默认书写区 |
| --- | --- | --- |
| 数学口算/填结果 | 默认三栏，长题自动减栏 | 至少 12 mm 高的作答空间 |
| 数学竖式 | 默认双栏，题干在上 | 48 mm 空白区，不预填计算过程 |
| 数学脱式/混合运算 | 默认双栏，过宽时单栏 | 56 mm 分步书写区 |
| 数学应用题 | 默认单栏，条件与问题相邻 | 64 mm 书写区，可逐题增加 |
| 语文看拼音写词语 | 拼音与对应字格成组 | 默认 11 mm 田字格；低年级可选 12 mm |
| 语文词语抄写 | 范字与练习格成组 | 默认 3 次，可调整，不自动描红 |
| 英语单词/短语默写 | 可选中译英、英译中；默认双栏 | 横线或四线格，长短语自动增加空间 |
| 三科选择/判断/填空 | 通用题干与选项模板 | 保留原题空格，必要时追加作答行 |
| 阅读理解/图文复合题 | 默认单栏，材料与小题关联 | 每小题独立设置书写区，允许有提示地续页 |

以上数值为可调整的初始模板参数，不是教学标准。系统不得把所有题型都简化为相同高度的空白。

### FR-06 A3/A4 排版与分页

- 对话中提供标准、紧凑、宽松方案：标准按题型默认值，紧凑减少题间距和可调整留白，宽松增加书写区；三个方案均遵守字号与书写区下限。具体参数在模板验证时锁定，不以方案名称代替实际设置。
- 首版支持 A3（297 × 420 mm）、A4（210 × 297 mm），默认均为纵向。默认四边 14 mm 边距，页眉、页脚从所选纸型的正文可用区域中扣除。
- 纸型选择优先级：用户明确指定的 A3/A4 > 用户任务描述包含“试卷”时推断为 A3 > 默认 A4。在排版摘要中说明所选纸型；推断结果不是额外确认门槛，家长可随时改选。
- 每次按选定纸型生成预览和 PDF；用户要求两种版本时分别生成并标注纸型。切换纸型后按新页面尺寸重新测量与分页，保持题目内容、字号和毫米制书写区设置，不将整页简单等比缩放。
- 默认题干 14 pt，允许 12–20 pt；低年级可建议 16 pt。任何自动排版都不得低于 12 pt。
- 支持自动推荐及手动选择单/双/三栏；题目、公式或图示放不下时先减少栏数，再增加页数。
- 答题格和书写区按毫米定义，不随题干字号缩小。家长可以选紧凑/标准/宽松留白或逐题设置，但系统必须展示其对页数的影响。
- 默认按试卷方式组织：先归并学科，再按各科题型顺序形成大题，同题型内保留相对顺序；同科共享页面，切换学科新起一页。大题使用中文序号、题型名称与题数，标题与首题一起分页，跨页显示“（续）”；英语中译英与英译中分别成组，阅读材料与关联小题保持整体。
- 题干、选项、关联图示及最小书写区优先作为整体分页；标题不可孤立在页尾。
- 单题超过一页时，按材料、小题、书写区等逻辑块续页，显示“第 N 题（续）”，保持统一题号。
- 全卷小题号按分组后的试卷顺序连续且唯一，学生卷与答案册共用分组及题号；每科大题序号从“一”开始，原题号作为来源信息保留。页脚显示当前页/总页数。
- 若用户限制页数而内容放不下，说明超出原因，允许减少题量、调整合法字号或留白；不得静默丢题、越界或压缩到不可作答。
- 同一字体、字号、题目和设置下，重复生成的题序与分页应稳定。

### FR-07 预览与排版修改

- 预览与 PDF 使用同一份已确认内容、字体资源和页面设置。
- 在对话中返回当前纸型、入选题数、已确认题数、排除题数、总页数、仍需处理的问题，以及可打开的 HTML 链接和实际页面缩略图。
- 家长可切换 A3/A4，或通过题号提出调整字号、栏数、书写区、顺序等要求；模型更新配置后重新分页，报告题目所在页及页数变化。
- 支持通过对话移除题目、恢复刚移除的题目；生成文件保留修订标识，方便核对本次预览与先前版本。
- 有未保存修改、预览未更新或正在生成时，在回复中明确状态；不允许将旧预览或旧 PDF 当作最新结果。
- 预览生成后允许家长继续调整；用户已明确要求直接导出时，不额外设置固定的“同意预览”口令。未决疑点仍必须先处理。

### FR-08 PDF 导出与打印

- 导出学生版 PDF 为 P0 必须完成的结果；仅生成 HTML 不算导出成功。
- 输出文件名包含可读标题、纸型和日期；重复导出不能误用旧缓存文件。
- 等待字体、题图、公式和最终分页完成后导出；缺少必要资源或发现内容越界时终止本次导出并定位问题。
- PDF 页面必须符合选定的 A3 或 A4 尺寸，纸型、题数、顺序、题面与最终预览一致，无浏览器附加网址、时间等页眉页脚。
- 文字与格线以黑白打印清晰为目标；颜色不能成为理解题意或区分状态的唯一方式。
- 在对话中提供可访问的 PDF 文件链接并标注纸型，HTML 预览可提供打印入口；提示打印时选择对应的 A3/A4 纸张、实际大小 100%，不自动发送打印机任务。
- 导出失败保留已确认题目与设置，允许单独重试，无需重新上传。

### FR-09 可选答案册

- 默认不生成答案；家长主动选择后，独立导出答案册，不与学生卷合并。
- 仅包含有明确来源或经核对的参考答案，学生原作答不能作为正确答案直接使用。
- 数字四则运算可以用确定性计算器核对；开放题、自然语言应用题和拼音必须单独校对，不能用格式检查代替内容核对。
- 无法核对答案的题目允许在答案册标为“未提供”，不能生成猜测答案；学生卷仍可独立导出。
- 学生输出采用字段白名单，不把参考答案、原始模型响应或内部工作数据嵌入学生 HTML/PDF。

### FR-10 任务保存与异常恢复

- 在工作目录保存任务 JSON，包含题目、来源引用、疑点、确认状态、排版设置与修订号；报告保存位置，写入失败时不能承诺已保存。
- 从已有任务继续时读取文件，不仅依赖对话上下文。宿主附件可能失效；必要题图应保存为任务资源，缺少资源时要求重新关联来源后再导出。
- 替换/重新识别某个来源时，保留已人工编辑的题目版本；与家长修改冲突时，列出差异再决定采用哪个版本。
- 识别或导出失败只重试失败阶段，不重置已确认题目；每次生成使用独立修订目录，避免覆盖已有成果或混入旧答案册。

### FR-11 skill 包与调用约定

- `SKILL.md` 描述触发场景、输入要求、六步流程、何时追问、如何生成及交付前检查；家长不需要手动编写 JSON 或运行命令。
- 模型负责语义理解与对话，结构化任务协议连接模型和脚本；脚本负责校验、排版、预览、PDF 导出与报告。
- 包内按需包含 `references/`（题型与数据协议）、`scripts/`（生成与校验）、`assets/`（模板与字体）及样例；入口保持精简，细则按学科读取。
- 使用相对 skill 目录的路径，记录依赖安装与运行方式；在新工作目录中完成一次安装、输入、预览、导出的闭环，验证不依赖开发机的绝对路径。
- 在运行前检查宿主读取图片、写文件、执行脚本及导出 PDF 的能力。能力缺失时说明具体阻塞与已有成果；仅有 HTML 时明确 PDF 尚未完成。

## 7. 实现决策与技术边界

### 7.1 模块职责

| 模块 | 职责 | 关键边界 |
| --- | --- | --- |
| skill 入口 | 定义触发场景、六步流程、按需读取规则与交付要求 | 不把模型理解能力描述为脚本能力 |
| 宿主模型与对话 | 读取文字/图片、分题、学科题型判断、疑点确认、理解修改指令 | 不默认判分、补题、解题或改题；不能读图时明确说明 |
| 任务数据与资源 | 来源索引、选题、题图、确认状态、排序与修订保存 | 题目稳定 ID 与版本可追溯；资源缺失不带病导出 |
| 排版脚本与模板 | 输入校验、文本测量、答题空间、分页、HTML 与页面缩略图 | 所选 A3/A4 页面尺寸与最低字号是硬约束 |
| PDF 导出与检查脚本 | 打印布局复核、字体/图像等待、PDF 输出与报告 | 失败不返回不完整文件作为成功结果 |

### 7.2 Pretext 的使用方式

- 用 Pretext 测量普通题干和行内文本，复用准备结果，在不同栏宽和字号方案下计算行数与高度。
- 学科模板、答题区、图形保留、分页与 PDF 导出由 skill 内的脚本与模板实现；Pretext 本身不提供 OCR、题意判断或完整文档分页。
- 复杂公式、表格、拼音格及最终页边界以浏览器实际打印布局复核为准；不以避免 DOM 测量为产品目标。
- 建议公式采用 KaTeX，页面使用 HTML/CSS，PDF 使用固定 Chromium 环境与 Playwright 导出。
- 打印字体使用可嵌入、许可明确的固定字体；等待实际所需字体加载完成，测量与绘制使用相同字体和尺寸。
- 首版不修改 Pretext 核心，也不承诺跨浏览器自行打印的分页完全相同；下载 PDF 为标准交付物。

### 7.3 现有实现可复用范围

当前环境的 `study-sheet` 已有 Pretext 文本测量、三科部分模板、毫米制书写区、实际布局分页、A4 打印规则、公式渲染与 PDF 导出代码，可作为排版模块的实现参考。

复用前需验证依赖、许可、样张与浏览器测试。现有实现已经采用“宿主理解内容 → 结构化 JSON → 脚本生成 HTML/PDF”的 skill 分工，可以作为基础参考。其脚本不提供 OCR，也不提供网页题目编辑器；这两项不要求在本项目中建设独立服务。

现有生成器不支持必要题图的嵌入与渲染；本项目若保留图文题 P0 范围，必须补齐图像资源、图文内容块与分页支持。不能仅靠宿主“看懂图片”就宣称输出支持题图。

现有 A4 打印规则不能直接视为已支持 A3；复用时需将页面尺寸、可用区域、预览和 PDF 导出参数统一按纸型配置，并分别验收 A3 与 A4。

本项目默认维护独立 skill 包，Pretext 作为依赖引入；复用代码需随包提供，不依赖开发机上的 `study-sheet` 绝对路径。是否最终合并为现有 skill 的扩展可后续决定。首版采用本地脚本生成文件，无需独立前后端、识别服务、数据库或 Redis。

### 7.4 核心数据约束

- `Source`：来源 ID、文字/图片类型、来源位置描述、可选区域坐标、资源引用、处理状态。
- `Question`：稳定 ID、来源引用、学科、题型、题干/选项/图示/小题等内容块、是否入选、确认状态、疑点、书写区、可选参考答案。
- `Worksheet`：稳定 ID、标题、可选年级、题目有序列表、纸型（`paperSize: A3 | A4`）、页面设置、排版方案、当前流程阶段与修订版本。
- `Export`：对应练习版本、纸型、题目数量、页数、学生卷/答案册类型、预览/PDF 文件引用、检查结果、状态与错误原因。

内容块要能表达普通文字、数学公式、题图和复合小题，不能只保存整题的一段纯文本。题目确认状态与题图“是否仍含作答”分别记录。

### 7.5 状态与失效规则

- 来源：待处理 → 处理中 → 完成 / 部分完成 / 失败 / 已取消。
- 题目：待确认 → 已确认；无疑点且校验通过，或疑点已经家长明确处理后，才能标记已确认。题意相关编辑使其返回待确认；不入选的题不阻塞其他题。
- 练习阶段：素材接收 → 题目整理 → 疑点确认 → 排版选择 → 预览生成 → PDF 导出。允许返回前序阶段；无疑点时可直接通过疑点确认阶段，已有排版偏好时沿用。
- 练习就绪状态：草稿 → 可预览 → 可导出；入选题仍有未解决疑点时，可以查看带提示的草稿预览，但不能导出正式学生卷。
- 导出：等待 → 生成中 → 成功 / 失败 / 已取消；内容或设置变化后，上一次导出标记为旧版本。
- 并发识别或导出完成时按修订版本核对，旧请求不得覆盖新题面或替换当前下载文件。

## 8. 体验与非功能要求

### 8.1 对话与预览体验

- 每次回复围绕当前阶段给出必要结果和下一步，题目较多时先给清单与疑点，不在对话中重复整份工作 JSON。
- 疑点集中列出并关联题号、来源和具体内容；不重复追问已经回答的信息，家长可一次回复多个题目的修正。
- 家长使用自然语言即可完成六步流程，不要求接触命令行、数据协议或内部模型配置。
- 预览 HTML 按所选 A3/A4 纸型呈现内容并标注纸型，支持桌面与手机缩放查看；预览缩放不改变打印物理尺寸。
- 如增加预览工具栏，沿用用户确认的 WeKnora 浅色规范，提供可见焦点与文字状态；宿主聊天界面的布局由宿主负责。
- 打印题干按 pt、纸张与书写区按 mm，浏览器显示比例不参与打印尺寸计算。

### 8.2 性能与可靠性

- 在宿主允许的情况下报告真实处理阶段及已处理数量，不虚构后台任务或百分比进度。
- 失败项可以单独重试；取消能力以宿主实际执行工具为准，不把不可中断的步骤描述为已取消。
- 记录模型整理、疑点等待、预览生成、PDF 导出各阶段耗时。初始脚本目标：20 道普通题的预览生成与 PDF 导出分别不超过 10 秒；需在约定设备中验证，依赖安装、模型处理、用户等待和复杂图片题另行记录。
- 初始能力包络按 100 题与每批 10 张图片验证；实际发布上限以测试结果和宿主限制为准。
- PDF 生成不依赖家长设备是否安装指定中文字体；可重复导出，字体或资源失败必须可诊断。

### 8.3 素材使用与保存

- 只收集本次处理必需的素材；学生姓名、学校与年级均非强制。
- 图片由当前宿主的视觉能力处理，素材使用受宿主政策约束；skill 不额外调用独立第三方 OCR 服务，也不承诺宿主附件的保留期限。
- 本地工作文件与生成结果保存在明确的任务目录，不能将关闭对话等同于删除文件；家长要求清理时，说明并处理本次任务范围内的文件。输出链接的有效期受宿主文件交付方式约束。
- 日志记录任务状态与必要错误信息，默认不记录原始照片、完整题面或参考答案。

## 9. 测试决策与验收标准

### 9.1 验收材料

建立固定样例集，至少包括三科共 60 道真实形态题目：每科不少于 20 道；另覆盖纯文本、清晰照片、倾斜/模糊照片、带作答图片、多张图片中的关联材料、必要图示和超长题。PDF 来源样例在扩展该输入能力时加入。

三科样张均覆盖 A3、A4 两种纸型，并用同一组题目验证纸型切换后的重新分页、字号与书写区尺寸。

人工制作来源对照答案：每道题的边界、题干、图示、所属小题和关键字符。识别是否正确、家长确认是否有效、排版是否正确分别记录。

### 9.2 必须通过的验收项

| 编号 | 场景 | 验收结果 |
| --- | --- | --- |
| AC-01 | 文字、照片与截图混合输入 | 来源均有编号与状态；不可读或不支持素材明确失败，不影响其他素材 |
| AC-02 | 整页试卷选题、候选题合并/拆分 | 只输出家长入选题；题干、选项、图示及小题关联完整 |
| AC-03 | 数学易混符号、拼音声调、英语词形 | 通过对话按题号集中确认；部分回复不误确认其余项，修正后导出与修改一致 |
| AC-04 | 一题待确认，其余题已确认 | 正式导出提示具体题目；排除该题后可导出其余题，不静默跳过 |
| AC-05 | 竖式、脱式、应用题、田字格、四线格 | 书写区符合配置毫米尺寸，不随字号缩小，未预填学生应作答内容 |
| AC-06 | 大图、长公式、阅读材料、多小题 | 不裁掉必要内容；减栏或逻辑续页，续页题号与关联明确 |
| AC-07 | 页尾仅剩少量空间、限页数但内容过多 | 题目合理换页或提示调整，不越界、不丢题、题干不低于 12 pt |
| AC-08 | 修改题目、纸型、顺序、字号或留白后导出 | 预览与下载均为最新版本；旧的异步结果不能覆盖新版本 |
| AC-09 | 学生卷与可选答案册 | 两份文件清楚区分；学生 HTML/PDF 不包含隐藏答案和内部工作 JSON；经明确同意保留的原图作答另有提示 |
| AC-10 | A3/A4 PDF 尺寸与内容检查 | 每页符合选定纸型，尺寸误差不超过 1 pt；页数与预览一致，无异常空白页 |
| AC-11 | 字体/图片加载失败、识别超时、导出失败 | 显示可执行的处理提示；保留已确认工作；可重试且不误报成功 |
| AC-12 | 从已保存任务继续、写入失败、来源附件失效 | 题目、确认状态与设置恢复准确；缺题图阻止导出；未保存时不误报成功 |
| AC-13 | 在目标 AI 宿主中完成六步流程 | 通过自然语言提供素材、确认疑点、选择排版、查看预览并取得 PDF，无需手写 JSON 或执行命令 |
| AC-14 | 纸质打印样张 | 至少抽打数学、语文、英语各一套，样张覆盖 A3 与 A4；题图、格线和文字清晰，作答空间可用 |
| AC-15 | 无疑点输入与已有排版偏好 | 自动通过无疑点阶段并沿用偏好；不为凑齐六轮对话而重复追问 |
| AC-16 | 预览后修改与已授权直接导出 | 修改后重建预览，PDF 对应同一修订；无修改且已要求导出时能继续完成 |
| AC-17 | 宿主缺少视觉能力或 PDF 导出依赖 | 明确缺失能力与已完成部分，不伪造转录，不将 HTML 当 PDF 交付 |
| AC-18 | skill 在新工作目录中运行 | 相对路径、依赖说明和生成入口可用，不依赖开发机上的其他 skill 目录 |
| AC-19 | 纸型推断与明确选择 | “生成一份试卷”默认 A3；“生成 A4 试卷”使用 A4；未提纸型与“试卷”时默认 A4，并在摘要中说明 |
| AC-20 | 预览后切换 A3/A4 或要求两种版本 | 切换后重新分页，字号和书写区尺寸保持设置值；预览与 PDF 纸型一致，两种版本的文件和链接标识清楚 |

### 9.3 验证层次

- 数据与公开接口：确认状态、版本失效、题目完整性、学生字段投影、错误恢复。
- 宿主对话：六步衔接、疑点追问、部分回复、排版选择与修改回路。
- 浏览器工件：HTML 预览、页面几何边界、资源就绪、最终打印布局。
- PDF 工件：纸张尺寸、题数与页数对账、字体与题图、学生卷/答案册隔离。
- 人工评估：原题含义、符号、拼音、图文关联和真实纸质书写体验。

不能仅以脚本退出码或生成了文件判断成功；交付前必须查看实际 PDF 页面截图。不得以单元测试替代图片题和跨页题的页面检查。

## 10. 非目标

- 首版不自动批改学生作答、不诊断学习能力、不提供学习效果承诺。
- 不默认生成同类题、完整解题过程、知识图谱或个性化复习计划。
- 不做完整在线题库、班级管理、教师协作、付费系统或跨设备账号体系。
- 不建设独立网页工作台、网页题目编辑器、OCR 服务或常驻后端；输入理解使用宿主能力，文件生成使用 skill 脚本。
- 不把手写去除、任意版面识别、复杂图形重建描述为无条件准确。
- 不支持自动发送打印机任务，也不以在线分享页面代替 PDF 下载。
- 不为了本产品扩展或重写 Pretext 核心；本次 PRD 更新不包含 skill 编码、安装或服务部署。
