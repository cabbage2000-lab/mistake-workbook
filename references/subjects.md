# 三科模板与实际参数

保留原题，未知类型使用 generic。模型对题意负责；模板不进行 OCR、不判断错题、不自动补题或解题。

| type | 学科场景 | 默认栏数 | 标准书写空间 |
| --- | --- | --- | --- |
| oral | 数学口算 | 3 | 12mm 空白 |
| vertical | 数学竖式 | 2 | 48mm 空白 |
| mixed | 数学脱式/混合 | 2 | 56mm 空白 |
| application | 数学应用 | 1 | 64mm 空白 |
| pinyin | 语文看拼音写词语 | 2 | 拼音 + 11mm 田字格 |
| copy | 语文抄写 | 2 | 范字 + 3 遍字格 |
| dictation | 英语单词/短语 | 2 | 14mm 横线，可选 four-line |
| choice/judgment/fill | 三科通用 | 1 | 默认追加 8mm；原题已有足够作答位置时设 mm:0 |
| reading | 阅读/图文复合 | 1 | 每个 subquestion 独立空间 |
| generic | 通用题 | 1 | 24mm，数学空白，其他学科横线 |

数学题及其子题的附加作答区默认使用无边框空白，不画横线或线格；保留原有毫米高度、题内填空线、公式和必要题图/表格。只有用户明确要求辅助线时才指定 workspace.style:lines 或 four-line。

题间距：标准 5mm、紧凑 3mm、宽松 7mm。默认空间乘数：标准 1、紧凑 .85、宽松 1.25；逐题显式 mm/lines 不乘，仅指定 style 仍按预设和内容计算空间。下限：口算 12mm、竖式 40mm、脱式/应用 48mm、默写 14mm、通用至少 8mm；拼音/抄写/阅读外层及选择/判断/填空可以显式设 0，阅读子题默认 24mm。格子严格 11/12mm，不随字号或方案缩小。

线格按实际作答内容选择，不按题号交替：英文单词、句子书写训练可用 four-line；英译中使用中文横线，题内填空不重复追加作答行。普通横线每行至少 8mm，单词/短语默写横线每行至少 14mm；指定毫米的剩余空间均分到完整行，避免末尾出现挤在一起的双线。四线格每组 18mm，四条实线相距 4mm，第三条为书写基线；不足整组的毫米高度向上补足，不能压缩四线格。workspace.lines 表示当前样式的完整书写行数，四线格一行即一组四条线。仅设置样式时长短语仍自动扩容；显式 mm/lines 固定空间（四线格按完整组补足），宿主需核对是否够写。

默认按试卷方式组织：先归并学科（学科顺序取入选题首次出现顺序），再按下面顺序归并题型；同组内保留录入或 reorder 后的相对顺序。没有题目的分组不显示；其他合法题型按协议枚举顺序补在后面。未知类型使用综合题，已知题型应准确填写，不靠模板猜测题干。

- 数学：填空题 → 选择题 → 判断题 → 口算题 → 竖式计算 → 脱式计算 → 解决问题 → 图表与材料题 → 综合题。
- 语文：看拼音写词语 → 词语抄写 → 词语默写 → 选择题 → 判断题 → 填空题 → 综合题 → 阅读理解。
- 英语：词语默写（中译英、英译中分别成组）→ 选择题 → 判断题 → 填空题 → 综合题 → 阅读理解。

每科大题从“一”起编号并标注题数，小题全卷连续编号；学生卷和答案册保持一致，原题号仍在来源记录中。题型间另起一行，同科共享页面，换科新起一页。大题标题与首题一起排版，跨页显示大题“（续）”。优先保持题干、选项、图示与书写区整题；超页按文本段、图、表格行组、子题或书写行续页，不拆公式/字格；阅读材料与其子题不能为了分类拆散。无法安全分割的一大块会终止并给出题号。

数学核对负号、小数点、分数、乘除、单位与图示标注；不预填竖式过程。语文重点核对多音字、轻声、ü、声调及生僻字；拼音块只写题目拼音，不在学生卷附答案字。抄写范字是家长要求的公开内容，不自动描红。英语保持大小写、标点、词形；默认中译英，改 en-zh 只显示英文提示，长短语优先减栏或增加书写空间。
