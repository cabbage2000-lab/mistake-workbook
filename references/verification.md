# 交付检查

脚本在浏览器预览中检查页面边界、题图加载、题数和题序，并在 `.docx` 中核对文档结构、题数、题号和 A3/A4 纸型。交付当前结果前，检查 `report.status=success`、`status.latest.stale=false` 和 `student.docx` 路径。用户要求答案时同时检查 `answers.docx`。未决题、未核对来源、未经确认的题图作答和缺失资源会阻止正式导出。

1. 查看 HTML 和逐页 PNG，抽查题图、公式、拼音、物理留白和跨页内容。检查学科、题型与题号和原题一致。
2. 能打开 Word 文件时，在 Word 或 WPS 的打印布局查看 A3/A4 纸型、题图、公式、表格、书写区和末页。字体替换和编辑会改变 Word 分页，报告中的页数仅对应浏览器。常见公式可直接编辑，转换器无法表示的公式用预览图像保留，报告标明题号。只完成结构检查时，向用户说明实际 Word 分页待核对。
3. 学生 Word 检查无参考答案、默写目标和内部工作资料。按家长确认保留原作答的题图带可见标注。独立 Word 答案册保持同一题号，未核对答案显示“未提供”。
4. 返回 `.docx`、HTML 和逐页 PNG 链接，纸型、题数、修订、排除项和保存位置。发生失败时说明已生成的文件和可重试的步骤。

真实来源转录准确率和纸质打印需使用实际素材与打印样张验收。

## 排版专家复核

正常短卷走快速流程。脚本核对实际题序、打印边界和作答区高度，记录每页题号、书写毫米数与剩余空间。同行口算额外核对得数横线宽度。仅剩一行同组短题的末页优先尝试并回前页，放不下时尝试均分两页的题行。续页仅剩少量书写行时，尝试将相关题面一起移到续页。所有候选共用一次重排，复验题号、顺序、空间与越界；改善且无新增问题才留用。报告中的 `first-pass`、`revised`、`kept-original` 分别表示首版通过、采用二排、保留首版。

遇到 `layout.review.remaining` 或 Word 页图疑点，由宿主执行排版专家复核。读取原始要求、首版发现、留用版逐页题号及毫米数据，打开相应格式的页面图，连同前后页判断孩子能否读到题、找到对应答题位置并写得下。记录具体页码、题号、观察和处理。应用题的整块留白、明确要求的长书写区、普通末页余白可直接接受。发现实际裁切、字格挤压、选项缺失等影响作答的问题时修复并复验。局部问题优先调整该题栏数或书写区；需要比较新方案时，在独立临时任务中保留相同素材和确认状态试排，确认改善再通过原任务的 `expectedRevision` 和 `apply` 保存。仅在明确要求冲突时请家长取舍。

## Word 打印页

正式导出遇到混合题型、阅读或长材料、图表公式、单题续页、重排或页数上限时，脚本用本机 LibreOffice Writer 打开刚生成的 DOCX，转换结果仅用于核验。Python 和 PyMuPDF 读取每一页，输出与浏览器缩略图区分命名的 Word 页图。支持通过 `MISTAKE_WORKBOOK_SOFFICE` 和 `MISTAKE_WORKBOOK_PYTHON` 指定可执行程序。安装 PyMuPDF 时使用同一 Python 环境。

- `wordReview.status=structure-only` 表示普通卷通过结构检查。若报告页数，注明来自浏览器预览。
- `rendered` 表示已有 Writer 页图。宿主抽看风险页及末页，核对题图、表格断行和书写空间。
- `needs-review` 表示页数差异或页面异常。打开 `actual.findings` 标出的页及相邻页。正常的字体分页差异可直接接受；明确限页的卷超过上限时导出失败。
- `unavailable` 会给出缺失能力或渲染错误。可在本机 Word/WPS 打印布局核对；仅完成结构检查时向用户标明实际 Word 分页待核对。

日常验收记录老师或家长实际打印前是否手调，以及手调的格式、页码和原因。直接打印率按“未手调即打印份数 / 有实际反馈的已打印份数”统计。将重复出现的问题和对应题型加入回归样例。
