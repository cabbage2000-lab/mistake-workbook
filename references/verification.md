# 交付检查

脚本自动等待字体、图像、公式和最终分页，检查每页正文边界、非空页、题目 ID 与顺序、PDF 页数和 A3/A4 尺寸（≤1pt 误差）。`report.status=success` 且 `status.latest.stale=false` 才是当前结果。未决题、未核对来源范围、含作答题图未获确认、限页数不足、图/字体缺失均阻止正式导出。

生成后还需宿主实际查看工件：

1. 打开 HTML 和页面 PNG，确认图示、小题、公式、拼音和毫米留白可读。核对学科/题型分组、大题标题及题数、连续小题号；标题不能孤立在页尾，续页保留题型提示。逐页可查，检查首尾页与续页，不只检查首屏。
2. 查看实际 PDF 渲染的页面截图，确认页数/纸型、题目齐全，无浏览器网址/时间、题目裁切或异常空白。可以用宿主 PDF 读取工具，或可用的 `pdftoppm` / PyMuPDF；这些是验收工具，不是生成运行依赖。不能用 HTML 截图替代实际 PDF 检查。
3. 学生卷检查无答案册内容、旧作答（明确保留的图除外）或内部 JSON。答案册独立下载，未核对答案写“未提供”。
4. 返回 HTML、实际页 PNG 和 PDF 文件链接，纸型、题数/页数、修订、排除项、保存位置及打印建议。失败时说清哪一步、哪些文件已有和重试方式，不宣称已完整成功。

真实纸质样张、照片转录正确率、5 位家长整理耗时和目标宿主自然语言闭环是人工验收，必须用实际素材/打印/用户测试记录。程序测试与合成样张不能替代这些数据。
